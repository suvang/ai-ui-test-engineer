# One Flow, and a Form field is never submitted

An Examination stays on the Target page, follows at most one same-origin Navigation link, and does not press a Button or submit a Form field. Following every link would turn a proof of the page into a crawl, and submitting a form or pressing a Button can change the Target page the user pointed at. The Test script checks that a Button is visible, fills a Form field and checks the value, and clicks only that one Navigation link.
